# ScaleMail — Keynote Demo

A single, self-contained HTML file for launching/presenting Scale Mail. **No build,
no server, no internet** — just open it. All data is fictional (demo only).

## How to present

1. Open `scalemail-keynote.html` in a browser (Chrome or Safari recommended).
2. On a wide screen it shows the keynote pitch panel beside an interactive iPhone.
   On a narrow screen it shows just the phone.
3. A guided tour auto-plays once on first load. Replay it any time with the
   **▶ Replay guided tour** button (bottom-right) or from the avatar → Replay Tutorial.

## What you can demo (everything is clickable)

- **Inbox** — color-coded rows, live unread badge, AI rank pills, thread counts, VIP stars.
- **Multi-account** — tap the account pill (or ☰) for the drawer: All Inboxes + Gmail /
  Outlook / iCloud, plus folders (Inbox, Sent, Drafts, Archive, Junk) and color labels.
  Switching an account filters the list.
- **Smart filter chips** — Urgent / Action / Meeting / Client / Newsletter / FYI with live counts.
- **AI Ask** — tap the ✦ button, hit Enter, get an answer about your inbox.
- **Reading view** — colored hero, AI summary, recommended next step, smart replies,
  Join-meeting button, VIP / snooze / archive, and a **More** menu.
- **More menu** — Teach AI (tell it how to treat a sender), Reply All, Forward,
  Move to folder, Mark unread, Report spam.
- **Threads** — multi-message emails show the earlier conversation inline.
- **Attachments** — tap a file to open the in-app document viewer.
- **Sender card** — tap the avatar/name for relationship stats + VIP toggle.
- **Snooze** — Later today / This evening / Tomorrow / This weekend / Next week.
- **Swipe Triage** — drag the card (or use the buttons): right = read, left = archive,
  up = snooze. Ends on inbox zero.
- **Onboarding** — full first-run setup (role → who matters → aggressiveness → connect
  mailboxes → profiling ring → ready). Replay it from the avatar menu → **Replay Setup**.
- **Calendar** — week strip + events with Join + RSVP status.
- **Daily Digest** — morning brief with the day's action items.
- **Inbox Health** — health ring + stats.
- **Categories** — the six auto-tags + a custom one, with colors.
- **Smart Cleanup** — bucketed low-priority mail (Newsletters, Receipts, Social,
  Promotions) you can archive in one tap.
- **Signature** — AI-generated signature with switchable styles (Modern/Classic/Minimal/Bold).
- **Compose** — new message / reply, with "Draft with AI".
- **Tabs** — Inbox, Starred, Sent, Drafts + center Compose. Avatar opens the full menu.

## Tips for the stage

- Press the browser's full-screen (F11) and zoom to taste; the phone auto-scales to height.
- The aurora background shifts color by context (red for urgent, gold for starred,
  indigo for meetings) — great on a big screen.
